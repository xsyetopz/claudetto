# 1.0.0 file tree (proposal)

The user reviews this tree before wave 1.
[Design](design.md) gives the rules of each folder, and [architecture](architecture.mmd) shows the parts at run time.

## `src/`

```text
src/
├── kernel/                           # shared code that the mod runtime can run
│   ├── slice.ts                      # Slice, ModHandler, Phase
│   ├── ports.ts                      # FileReader, Clock, ProcessRunner, Env
│   ├── budget.ts                     # shared runtime bounds
│   ├── spec-store.ts                 # store types and reader
│   ├── shell.ts                      # parse of a shell command into parts
│   ├── text.ts · json.ts · model.ts · errors.ts
│   └── node/                         # adapters with node:, bun:, Bun, for CLIs only
│       ├── fs.ts · process.ts · stdin.ts · paths.ts
├── fragments/                        # text parts that skills and agents include
├── wiki/                             # sources of generated wiki pages
└── plugins/
    ├── dotclaude/
    ├── dotclaude-codegraph/
    ├── dotclaude-browser/
    ├── dotclaude-docs/
    ├── dotclaude-sessions/
    └── dotclaude-lab/
```

Each slice has this shape, with only the parts that it needs:

```text
slices/<s>/
├── slice.ts                          # the manifest
├── domain/                           # pure code
├── ports.ts                          # interfaces that only this slice needs
├── adapters/
│   ├── mod.ts                        # mod handlers
│   ├── cli.ts                        # a CLI
│   └── hook.ts                       # a classic hook
├── limits.ts                         # the bounds of the slice
├── skills/<name>/SKILL.md
├── agents/<name>.md
├── styles/<name>.md
├── evals/<case>/                     # claude plugin eval cases
└── lab/*.test.ts                     # hook lab tests, run by claude plugin test
```
