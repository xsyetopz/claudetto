## Goal

Each change to a test, a hook file, or a check that I05 names gets an ask, unless it is on the safe list of its kind.

## Context

- I05 recipe 1 and 2 in `external/agent-failure-dossier/02-verification-and-honesty.md:133-137`: deny or ask on `tests/**`, `.github/**`, and hook files, and diff-review each change to an assertion.
- The `asks` slice already asks on a weaker test file or limits file (`asks/domain/testdiff.ts:1-9`), and on a lint config, a check config, a CI file, a hook file, a settings file, and a check script (`asks/domain/kinds.ts:1-3`).
- The `permissions.deny` list at `prompt/slice.ts:125-144` holds credentials only.
- `design.md`, "Asks".

## Steps

1. Map each item of I05 recipe 1 and 2 on a kind of `kinds.ts`, and write the map in the evidence file.
2. For each item with no kind, such as an eval case, a grader, a fixture, or a `lab/` test, add the kind and its file list in `limits.ts`.
3. Tests `i05.test.ts`: for each kind, one change that asks and one safe change that does not ask, on the decision of the hook only.

## Acceptance

- The verify command passes.
- Each item of the recipe has a kind or a reason for none in the evidence file.

## Boundaries

- Do not add a deny.
  A user can approve an ask, and a deny would stop the work of the user.
- Do not change `testdiff.ts`, which P140 owns.
- Tests check decisions, not reason text (REQ-17).
