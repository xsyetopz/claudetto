# Code of conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The link has the full text.

In short:

- Be respectful and welcoming to all people.
- Accept feedback with grace, and give it with care.
- Do not harass, insult, or attack a person, and do not share private information about them.

To report a problem, contact the maintainer `xsyetopz` through GitHub.
Use a private channel, such as a security advisory, when the report is sensitive.
The maintainer reviews each report and keeps the reporter private.
