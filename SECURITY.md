# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Do not open a public issue.
Use the private vulnerability reporting of GitHub:
open the [Security tab](https://github.com/xsyetopz/claudetto/security/advisories/new)
of `xsyetopz/claudetto` and choose "Report a vulnerability".

The plugins in this repository run hooks that execute shell commands on your machine.
Include the plugin name and version, the Claude Code version, and the steps to reproduce.
