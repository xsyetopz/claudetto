# Test Diet

Every path on this page is the path a file had on 2026-10-28, and the tree it surveys now lives under `archive/`. Two later moves renamed what it names, so a path here is read by adding `archive/` in front of it rather than by looking for it in place: the unit tests went into a `__tests__/` folder beside the source each covers, with the suffix `.spec.ts`, and the `dev/` folder became `claudekit/`. The paths are kept as they were read, because the line counts and the marks below were taken at them.

On 2026-10-28 I ran `find . -name '*.test.ts' -not -path './node_modules/*' | sort` and `wc -l` on every file it printed. The `find` command lists 241 files, and `wc -l` totals 30381 lines. The module column comes from the first comment line of each file and from its path. A cell reads `not stated in the file` when no comment says it. The `Named by a defect` column says `yes` when `git log --format='%h %s' -- <file>` shows a commit whose subject starts with `fix` or whose body names a `defect` or a `bug`, or when `docs/early-stops.md` names the file, and it says `no` otherwise.

The `Mark` column is task 12.2. Each file carries the first mark that applies to the majority of its tests, in this order, and `Source` quotes a line of the file that shows the mark:

- `defect`: the file guards a past defect, which is the `yes` of the `Named by a defect` column.
- `mechanical`: it checks a rule a linter or a hook can check, such as a constant against another constant, or a file listing (`mattpocock/skills` `engineering/retro`, `references.md:229`).
- `coupled`: it mocks an internal collaborator, counts calls, or reaches a private method (`mattpocock/skills` `tdd/tests.md`, `references.md:234`).
- `tautological`: the expected value is recomputed the way the code computes it, from the same constant (same source).
- `unagreed-seam`: it calls an internal helper rather than the entry point its module agreed on (same source).
- `behavior`: none of the above. It sets up an input, makes one call, and checks a decision, an exit status, a file, or a returned value.

The 198 `behavior` files are not a diet candidate on this criterion. All 198 say `no` in the `Named by a defect` column, and the 4 `yes` rows are exactly the 4 `defect` rows, so no behavior test in the repo guards a recorded defect.

### How the Marks Were Made, and What That Limits

- Three agents marked the 241 files in parallel, one file set each. They used three different tie rules for a file whose tests split across marks, so their `mechanical` counts (6, 16, 27) were not comparable. Two further agents rechecked under one rule, the majority of the tests in the file: the first over all 49 `mechanical` rows (32 kept, 17 moved to `behavior`), the second over the 18 `coupled`, `tautological`, and `unagreed-seam` rows (4 kept, 14 moved). Every `coupled` mark fell in that second pass, because an injected fake that the test also reads as the observable is a seam, not a mock of an internal.
- The agents read filtered regions and test titles, not all 30381 lines. The first recheck agent decided five files from their titles alone. So a mark is a reading of the file, not a line-by-line audit.
- `/tmp/td2/verify.ts` re-read the cited line of every row and checked the quoted fragment as a substring: `rows checked: 241`, `problems: 0`. It caught one wrong line number, `tests/claudetto/session/handoff/redact.test.ts:38` for a line that sits at `:37`.
- Close calls the recheck agents named, each of which could go either way: `tests/claudetto/session/handoff/trigger.test.ts` and `tests/claudetto/gate/limits.test.ts` between `mechanical` and `behavior`, and `budget.test.ts`, `imports.test.ts`, and `faults.test.ts` in the first recheck. `tests/claudetto/shell/shell.test.ts` and `tests/claudetto/work/ground/claims.test.ts` would move to `unagreed-seam` if `parse`, `commands`, and `findUnsourced` were read as internal helpers rather than the entry point of their module.
- The test counts in the recheck came from `grep -c '^\s*test('`, which misses a `test.each` and a `for` loop around one block. So the count understates files such as `tests/claudetto/spec/parity/main.test.ts` and `tests/claudetto/jev/cli/errors.test.ts`. The mark does not rest on the count alone.
