## What it means for dotclaude

Each item is an inference, except where it says "stated".

- The start of a session has a fixed cost for each listed skill, agent, plugin, and MCP tool (stated).
  So the universal measure tool gives the start tokens by source, and it compares a start with and without a plugin.
  This is the first experiment of the comment.
- The usage tool reports the model calls of each run, the context that each call reads again, and the skills that a period did not use.
  This is the second experiment of the comment.
- A usage tool reports measurements, and it does not state a cause of a limit, because no primary source gives one.
- The descriptions of dotclaude (agents, skills, output style) are a fixed cost of each session, so they stay short (task 27.5).
