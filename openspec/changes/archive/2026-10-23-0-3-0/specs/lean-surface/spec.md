## Purpose

Each part that claudetto ships earns its place with an incident, a measured saving, or a need of the user, and each other part goes.

## ADDED Requirements

### Requirement: Evidence for Each Control

Each control in `src/wiki/claudetto/rationale/Controls.md` SHALL record an incident, a measured saving, or a user need, with its source.
No control SHALL record `incident: "none recorded"`.

#### Scenario: Control Scan

- **WHEN** a test reads each row of `src/wiki/claudetto/rationale/Controls.md`
- **THEN** no control has `incident: "none recorded"`, and each control has a source

### Requirement: Parts That Go

The release SHALL NOT ship the `claudetto-codegraph` plugin, the section rewrites of the `prompt` slice, the memory texts while memory is off, the `advise` tool, the print guard of `guard`, the `command.describe` hook that hides commands, or a feature that Claude Code 2.1.306 has built in.

#### Scenario: Marketplace

- **WHEN** a test reads `.claude-plugin/marketplace.json`
- **THEN** it has no `claudetto-codegraph` entry

#### Scenario: Built-In Duplicate

- **WHEN** Claude Code has a built-in feature for the work of a slice
- **THEN** the slice is cut, and the snippet sets the built-in feature instead

### Requirement: Readability Bounds

The lint step SHALL fail for a function above a cognitive complexity of 15 or a source file above the line bound in `tools/limits.ts`, in `src/` and `tools/`.

#### Scenario: Complex Function

- **WHEN** a function in `src/` has a cognitive complexity of 16
- **THEN** `just check` fails and names the function

### Requirement: Size Goes Down

The core plugin SHALL have fewer lines of TypeScript than 0.2.0 (10,623 lines, without tests).

#### Scenario: Line Count

- **WHEN** a test counts the lines of `src/plugins/claudetto/**/*.ts`
- **THEN** the count is below 10,623

### Requirement: No Build Header in User Files

A file that a skill copies into a user project SHALL NOT have the `Generated by` header of `just generate`.

#### Scenario: OpenSpec Template

- **WHEN** `/claudetto:propose` copies the `epic` schema into a project
- **THEN** no copied file has the `Generated by` line

### Requirement: Built-In Matrix

The release SHALL have a row in `research/replace-matrix.md` for each built-in tool, skill, command, agent, reminder kind, and background model call of Claude Code 2.1.306, with its cost and one decision: keep, replace and disable, or disable.
A built-in part that a claudetto tool does for less SHALL be disabled.

#### Scenario: New Built-In Part

- **WHEN** a test compares the tool and skill lists of a 2.1.306 capture with the matrix
- **THEN** each part has a row, and the test names each part with no row

#### Scenario: Cheaper Goal

- **WHEN** a goal can be checked by a command
- **THEN** a claudetto `Stop` command hook checks it with no model call, and `/goal` runs the claudetto goal in place of the built-in
