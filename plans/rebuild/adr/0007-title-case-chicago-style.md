# Titles Use Title Case in Chicago Style

## Context and Problem Statement

claudetto texts carry titles. The user ruled on 2026-11-04 that a title uses Title Case in Chicago style, as a claudetto text norm. The same answer set a test rule: before a built-in text is called fixed, look for an override and test it.

## Considered Options

- Sentence case for titles.
- Title Case in Chicago style.

## Decision Outcome

Chosen: Title Case in Chicago style, as a norm for claudetto text.

## Consequences

Every claudetto title follows it. The override-test rule lives in the project's CLAUDE.md, not in claudetto.
