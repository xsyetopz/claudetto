# No Verbatim User Quotes

## Context and Problem Statement

A handoff and an issues file copied the user's words verbatim. The user said not to quote them, and not to take their word for granted: each claim gets checked and the file brought to the latest state.

Transcript record tx-x02/user-not-quoted-verbatim: A curated issues file was full of verbatim user quotes.

## Considered Options

- Quote the user in plan and handoff files.
- Paraphrase the user and check each claim against the tree.

## Decision Outcome

Chosen: Paraphrase. No verbatim user quote in any plan file or handoff. Verify each stated fact before a file records it. Matches a settled decision of the plan; supersedes nothing.

## Consequences

A curated issues file carries zero "The user:" lines and no `openspec/` citation.
