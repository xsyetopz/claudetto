# Agrees anchored opener test

## Context and Problem Statement

The 321 decisions kept `AGREES` as an anchored deterministic opener test.

## Considered Options

* Keep `AGREES` anchored
* Drop it with the other word lists

## Decision Outcome

Chosen: Superseded: the user later ruled out word lists.

## Consequences

The opener is judged by typed questions only.
