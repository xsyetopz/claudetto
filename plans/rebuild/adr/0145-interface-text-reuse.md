# Interface Text Reuse

## Context and Problem Statement

May the rebuild take interface text of the original verbatim?

## Considered Options

* Take button and prompt text as shown
* Write every string anew

## Decision Outcome

Chosen option: take the interface text, because the user allowed it on 2026-10-27 and restated it on 2026-10-28 (the text is allowed to be taken, such as on buttons and prompts), and it is user-facing anyway.

## Consequences

* Good, because the interface matches the original.
* Bad, because the plan line says only that strings are reusable, with no decision date.
