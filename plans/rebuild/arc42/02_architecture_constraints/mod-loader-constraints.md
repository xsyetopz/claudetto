# Mod Loader Constraints

- [ ] **CON-007** claudetto shall write mod code under these loader limits: literal `on('<event>', ...)` with direct `$.<ns>.<method>()` calls (no loop, proxy, wrapper, or destructuring of `$`); one unmatched hook per event per module (an event two features hook unmatched belongs to `register.ts`; `on("session.start") is registered twice without a matcher` fails the module); the loader follows `$` only by name through function declarations, never arrows, lists, params, or exports (`claude plugin validate --strict` rejects "$ passed to a function expression outside the hook's own file"), so a module may pass `$` only to a top-level function declaration; `register.ts` chains `onSettingsRead` with `denyBuiltinFetch` (one unmatched `settings.read` per module); hooks import code files only (their own files and `"claude-code"`; not `node:fs`, `node:path`, a package, or JSON); every model-read text in one `texts` file; strict TypeScript flags kept (`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`); `$.tool.register` is unavailable in `classic.SessionStart` ("no session is bound"), so register in the single `session.start` hook; a `command.run` hook answering `goal` without `next()` replaces built-in `/goal`.
  Acceptance: `claude plugin validate --strict` passes on every module. Verification: test.
