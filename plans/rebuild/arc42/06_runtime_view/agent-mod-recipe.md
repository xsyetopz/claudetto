- [ ] **RT-002** The mod pipeline for the Agent tool runs in four hooks: `tool.describe` for `Agent` drops "(general-purpose by default)" and says `name` addresses the agent (SendMessage reaches it); `agent.offer` withholds built-ins (a plugin agent never takes a built-in's name, because Claude Code prefixes it; `CLAUDE_CODE_DISABLE_EXPLORE_PLAN_AGENTS` gates Explore and Plan); `tool.call` maps Artemis and Metis to a read-only built-in with `run_in_background:false` and sets `result.agentType="Explore"` (this removes the `agentId:` trailer, about 194 B per result, computed and confirmed by a fake-API probe on 2.1.319); `prompt.attachment` cuts `agent_listing_delta` to lines starting "- " joined by newlines, with null and other types unchanged. The Agent tool plus listing is 2,676-3,018 B against 6,747-7,293 stock; a paid run took 24,571 tokens and $0.034 against stock Explore 50,514 and $0.144, on the same 4 requests. A call the model writes in full is never rewritten. The Agent text says `isolation: "worktree"` for a committing agent; an agent without it runs in the lead's folder (measured). The spec follows the code for the Agent, AskUserQuestion, and Monitor wrappers. In 2.1.326 the release notes say a subagent isolated in a worktree refuses, in any repository, some Bash git commands that can rewrite branches shared with the checkout.
