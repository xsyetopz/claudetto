# Model Side Calls per Turn

- [ ] **RT-004** The model side calls per turn, measured by fake-API capture: a plain typed prompt makes 2 (Decider haiku, Stop grade haiku); a one-Bash turn makes 3 (adds grade sonnet); a force-delete of a foreign branch makes 5 (three Decider calls plus grade haiku and sonnet). With TYPESAFE_API_KEY the Decider makes no model call except the escalation fallback. After commit 85987b8e a plain turn makes 3, because the Stop register check adds one. Sources of each row: the Decider fallback (haiku) runs at prompt.submit (pin-ledger.ts, decider/fallback.ts:105); the grade (sonnet) runs when turn.results.length > 0; a foreign-branch force-delete is one pin plus two branch-gate Decider calls (gate/asked.ts:13 through gate/ownership.ts:36) plus grade haiku and sonnet; AskUserQuestion adds one settle call per call (ask-fix.ts:32); the TYPESAFE_API_KEY Decider calls a model only with escalate:true for the unsettled band (questions.ts:108, decider/settle.ts:125-146); the you-should-know side check makes at most 1 per turn, only with sideCheckEnabled=true on terminal or desktop (register.ts:108); the setup question makes 1 haiku advice call (setup/engine.ts:89); a Stop block adds 1 more main request, and an extra grade was not observed; a Stop grade is 1 haiku call plus 1 sonnet call when a tool ran. Decider timeout is 20 s, grade timeout is 15 s.
  Basis: measured for the first three rows; read from code for the rest. The AskUserQuestion, TYPESAFE_API_KEY escalation, you-should-know, setup, and Stop-block rows are read from code, not run: the model-call count run did not reach AskUserQuestion (the ask-fix Decider did not fire in -p), the you-should-know side check, the setup advice, or the Jev escalation, so those counts are unmeasured. The pin-ledger, gate, and decider paths are not in the baseline tree 088a227c.
