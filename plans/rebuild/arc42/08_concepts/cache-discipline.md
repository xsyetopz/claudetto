# Cache Discipline

- [ ] **CC-043** claudetto shall keep the prompt prefix byte-stable and judge token-savers by cache-hit rate. The cache is prefix-based and byte-exact: any rewrite of earlier context (compression plugins, trimming a stale tool result, reordering messages, a live-state file refreshed mid-prefix, a CLAUDE.md rewritten on boot) re-charges everything after the edit at full input price plus write premium. Defer a tool through `tool.describe` `isDeferred` only when `ToolSearch` is in `$.tool.list()` (otherwise turn 1 rewrites 3.9k tokens, 33 of 33 rows) and keep tools byte-identical across requests. The subagent cache TTL comes from the setting `subagentPromptCacheTtl` only (frontmatter `experimental.cacheTtl` also exists but applies only when no `subagentPromptCacheTtl` setting or env var is set; one way: the setting); setup writes `promptCacheTtl` 1h and the main conversation has 1h on subscription. Measured: plugin share of first-request cache read 72-77% against 67%; first request 7.57k against 16.55k tokens; cost-weighted input 17,270-18,760 against 25,415-25,773; Stop-block turns write 150-466 tokens against tails of 134-332; first request shrinks 43,382 to 19,675 B (19,392 at HEAD); 2 side calls per plain turn (3 with the Stop register check). A keepalive (ping every 55 min, max 5, then write `relay.md` and print a resume command; about 0.7 USD per 5 h) is optional and bounded (objection: Anthropic may restrict abuse); a handoff file is the default; see the OUT item on keep-warm. One fleet re-sent a 50 KB instruction file into every resumed conversation and invalidated the cache on every boot (found by measuring request bodies). Tool-output pruning that swaps stale results for a one-line summary plus id is a candidate for the compaction feature but invalidates the prefix at that point (missing). Preserve-thinking invalidates every thinking block on a prefix change.
  Acceptance: a request body shows byte-identical tools across two turns and a deferred tool only with `ToolSearch` listed; a stable boot file comes first and volatile state last or as a delta; `hash(instruction file) at session start; warn when it changes mid-session`; a token-saver is tested by freezing model, system prompt, tool schemas and order and comparing billed tokens. Verification: probe; test.
