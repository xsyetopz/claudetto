# Evidence Over Claims

- [ ] **CC-022** claudetto shall accept a claim only as tool output, an exit code, a diff, or rendered state, and trace every artifact, claim, test result, and decision to its source and authority.
  Acceptance: `accept(claim) = tool_output | exit_code | diff | rendered_state`; an agent summary, apology, self-report, and a second model's "done" are never evidence; an agent's self-report is checked against git changes, tool records, and the user's instructions, and an agent note never becomes evidence by repetition; each claim in a report cites a command, file, or user instruction. Honesty rules: reproduce what the user ran before stating a cause; audit output, not the report; show both reads when two differ; strike through corrections. None of these lets an agent notice an unseen mistake, which needs a test or a second model. Verification: inspection.
