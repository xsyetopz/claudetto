# Feature Owner Order

- [ ] **CC-019** A feature's owner is the first of seven in this order that a recorded check shows to keep its behavior: a settings key or built-in behavior, a classic hook, a skill, an output style, a rule file, a mod, removal. A setting or a classic hook comes first because it costs no mod code, keeps working under `--safe-mode`, and is checked by Claude Code itself. The feature map names the check, the Claude Code version, and the result. Surfaces in order of pick: tool deferral, command hiding, settings key, classic hook, skill, output style, rule file, mod. A call outside the agent form is denied with the exact form and never rewritten (a rewrite sends the call and later ones to the local classifier); `fork` and `statusline-setup` pass unchanged; `search`, `plan`, `sweep` carry `run_in_background`. The D321 mapping of built-in agents (`Explore` to `claudetto:search`, `Plan` to `claudetto:plan`, `general-purpose` to `claudetto:work`, withheld via `agent.offer`) is superseded by D323 (see [ADR-0126](../../adr/0126-builtin-agent-offer-mapping-superseded.md)).
