- [x] **RISK-515** The `spec` skill does not load when its shell injection cannot run (issue #85).
  - Category: spec, skill loading.
  - Cause: `skills/spec/SKILL.md` lists specs through `` !`git ls-files 'specs/*.md' 2>/dev/null || true` ``; Claude Code runs the injection through the Bash permission check and a shell before the skill loads, and `|| true` covers only git's exit code.
  - Event: 2026-11-21, claude 2.1.330: `claude -p --disallowedTools Bash "/claudetto-spec:spec ..."` answered `Shell command permission check failed for pattern ...` with 0 turns; under a nested Seatbelt, eval suite 1 answered `Shell command failed for pattern ...: sandbox-exec: sandbox_apply: Operation not permitted`.
  - Consequence: a user who denies Bash, or runs read-only, loses the whole skill over a convenience line.
  - Likelihood: 2
  - Impact: 3
  - Existing controls: none.
  - Response: treat.
  - Actions: remove the injection; the loop finds specs with Glob or `spec_check`.
  - Trigger: a skill edit.
  - Owner: spec
  - Status: mitigated 2026-11-21: the injection is gone; the skill tells Claude to Glob `specs/*.md` first.
  - Verified: 2026-11-21, claude 2.1.330: the `--disallowedTools Bash` probe now loads the skill (3 turns, no shell error), and eval suite 3 scores 1.0 with the plugin on all six current cases; Likelihood 2 × Impact 3 = 6.
  - Verified: 2026-11-24, claude 2.1.329, Haiku 5.5, `claude -p "/claudetto-spec:spec add a totalWithTax(cart, rate) function to src/cart.ts" --disallowedTools Bash --plugin-dir plugins/claudetto-spec`: 12 turns, no shell error, ending in `spec_check`; `just eval claudetto-spec` run `2026-11-24T03-08-24-158Z` (Opus 5.5) scored 0.92 to 1.00 with the plugin on all 13 cases.
  - Source: issue #85.

- [x] **RISK-519** The Stop-time `spec_check` treats the user's own uncommitted work as the agent's drift and orders it reverted or edited.
  - Category: spec, hook feedback.
  - Cause: `hooks/check/hard.ts:61` compares each requirement to `git show HEAD:<file>` and `hooks/check/hard.ts:68` compares each test to its staged copy, so a spec edit or a staged test the user made before the session counts as a change by the agent; `hooks/check/stop.ts:11` then tells the agent to restore the spec, and `hooks/texts.ts:33` calls each finding a blocking problem to fix.
  - Event: 2026-11-23, claude 2.1.330, Haiku 5.5, `claude plugin eval --ablation with-without`, two rounds of 3 runs per arm. `spec-edit-skill` (the user says they added DISC-2 to `specs/cart.md`): the hook flagged the user's uncommitted DISC-1 rewording, and Haiku restored DISC-1 to HEAD, erasing the user's edit; with-plugin 0/3 and 0/3, without-plugin 3/3 and 2/3. `spec-review-hollow-test` (the prompt says "Do not edit anything"): the hook flagged a `test.todo(` that the user's staged empty file did not hold, and Haiku edited `src/stock.test.ts`; with-plugin 0/3 and 0/3, without-plugin 1/3 and 3/3.
  - Consequence: the plugin destroys user work and breaks an explicit no-edit order, and it scores below vanilla on both cases, so it fails the ADR-0177 ship bar.
  - Likelihood: 4
  - Impact: 4
  - Existing controls: none; the hook text says to quote the request when it names the ID, which a user's own edit does not do.
  - Response: treat.
  - Actions: record the spec and staged-test state at SessionStart and compare against that record, so only changes made in the session count; write the Stop text as facts plus the next action, with no "blocking" verdict (RISK-346); add both cases as regression evals, with a no-plugin arm.

  - Owner: spec
  - Status: mitigated 2026-11-23. `hooks/check/baseline.ts` records each spec text, each test that already differed from the index, and the malformed and orphan findings at `session.start`; the Stop gate and `spec_check` both compare against that record, so the user's pre-session edits are the spec, not drift. The Stop text lists findings with the next action and no "blocking" verdict. SKILL.md states that the spec as the session found it is the spec to implement. The harder regression cases stay on the unmerged branch `test/harder-eval-cases` (RISK-529).
  - Verified: 2026-11-23, claude 2.1.330. `claude plugin test plugins/claudetto-spec`: 54 pass, 0 fail, six of them RISK-519 cases (Stop and `spec_check`, the user's edit versus the session's own).
