---
name: docs
description: Look up current library docs with the Context7 CLI.
---

Run one of these, with `--library-version V` when the project pins a version:

- `bunx ctx7 search "<question>" --library <name>`
- `bunx ctx7 library <name>`, then `bunx ctx7 docs <id> "<topic>"`

Answer with the library, its version, and the source URL that the output gives.
