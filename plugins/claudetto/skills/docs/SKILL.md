---
name: docs
description: Look up current library docs with the Context7 CLI.
---

1. `bunx ctx7 library <name> "<question>"` lists the library IDs and their versions.
2. `bunx ctx7 docs <id> "<question>"` returns the docs. When the project pins a version, add it to the ID, such as `/colinhacks/zod/v3.24.2`.

Answer with the library, its version, and the source URL that the output gives.
