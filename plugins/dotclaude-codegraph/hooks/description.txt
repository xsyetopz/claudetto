dotclaude-codegraph: `features/graph/cli.mjs` syncs the CodeGraph index at session start and adds one line about the graph, adds the callers of a searched symbol to `Grep` and `Glob` calls, and syncs the index in the background after an `Edit`, a `Write`, or a `git` command that changes the tree.
Each hook runs only in a project with a `.codegraph/` index.
