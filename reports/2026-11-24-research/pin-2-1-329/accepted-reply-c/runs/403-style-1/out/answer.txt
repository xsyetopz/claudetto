I set the proxy for Gradle in `gradle.properties`, which was empty. I haven't run a build, so it's untested. The repo has no Gradle project (no `build/` directory and no build scripts), and the proxy isn't reachable from here.

```
systemProp.http.proxyHost=proxy.corp
systemProp.http.proxyPort=3128
systemProp.https.proxyHost=proxy.corp
systemProp.https.proxyPort=3128
```

Gradle reads these as JVM system properties for both its dependency downloads and the wrapper download. I didn't add `nonProxyHosts`, because I don't know your internal hosts. If any internal repositories must bypass the proxy, add `systemProp.http.nonProxyHosts=...` and `systemProp.https.nonProxyHosts=...`.

I left the other steps alone because you only asked about Gradle. `.npmrc`, `pip.conf` and `.curlrc` are all empty too, and `env.sh` sets only `CI=1`. They will probably fail the same way. Do you want me to set the proxy for npm, pip and curl as well?
