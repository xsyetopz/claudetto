I looked at the repo, which has only `README.md`, `app.conf` and `config.json`. I haven't edited anything.

**What I see**
- **Two config files with no stated owner.** `app.conf` and `config.json` overlap, and the README only says "see config.json and app.conf". `retries` is set to 3 in both, so they could drift apart.
- **`app.conf` duplicates the port.** It has both `port=80` and `PORT=80`. Which one wins depends on whether the parser is case-sensitive.
- **`config.json` has a duplicate and unclear keys.** `retries` and `retries2` are both 3. `a`, `b.c` and `retries2` don't say what they're for.
- **`debug` is on.** `debug: true` is committed in the same file as the other settings.
- **Port 80 is privileged.** Binding to it usually needs root.

**What I'd change**
1. Use one format. I'd keep `config.json` and drop `app.conf`, or the reverse if something already reads `app.conf`.
2. Keep one `port` key, lowercase, and one `retries` key. Remove `retries2` once I confirm nothing reads it.
3. Give `a` and `b.c` real names, or remove them if they're unused.
4. Default `debug` to false, with a local override for development.
5. Update the README to say which file is the source of truth and what each key means.

I haven't found any code that reads these files, so I can't tell which keys are live. Tell me which file to keep and whether I should rename or remove the unclear keys. I'll make the edits then.
