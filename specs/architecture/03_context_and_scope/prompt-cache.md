- [x] **CTX-842** On a subscription login under claude 2.1.327, the main loop writes its cache with a 1h TTL. A non-fork subagent writes with no ttl field, which is the 5-minute default. `CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL=1h` gives the subagent 1h. A short-lived worker finishes within 5 minutes of its last write, so the default suits it, and its writes cost 1.25x instead of 2x at API list prices (on a subscription meter a 1h write costs only about 1.1 times a 5m write, CTX-846). A worker that waits longer than 5 minutes between turns re-writes its prefix. That is one more reason to end workers per slice (REQ-DELEGATION-065) rather than to raise their TTL.

- [x] **CTX-846** On the user's subscription a 1-hour cache write costs about 1.1 times a 5-minute write on the weekly meter (measured 1.09, bounds 0.92 to 1.30), not the API list ratio of 2 / 1.25 = 1.6. A 1h write cost about 0.32% of the weekly limit per 1M tokens on Opus 5.5, and a 5m write about 0.29%. That matches one Max subscriber's report: about 1.1 times, 0.3% per 1M, from 9.2M tokens. The meter does not follow API prices: one 1% step took $24.98 of API-equivalent value at 1h and $17.03 at 5m. A second run (same day) put Sonnet 5.5 at 1.06 (bounds 0.89 to 1.20), about 0.21% of the weekly limit per 1M 5m-write tokens; a Sonnet write costs about 0.69 of an Opus write on the meter against 0.50 at API prices. The same run measured a cache read at 0.033 of an Opus 5m write (bounds 0.028 to 0.036), about 0.0096% per 1M read tokens, against the list ratio of 0.08. A third run measured a Sonnet read at 0.033 of a Sonnet 5m write (bounds 0.031 to 0.035), about 0.0069% per 1M read tokens, so the ratio is the same on both models. Reads therefore weigh less on the meter than list prices imply, but not nothing: 0.033 puts the 2.72B subagent read tokens of the sessions measured in ADR-0110 at about 57% of subagent meter cost and the 68.4M write tokens at 43%. Subscriber cost models in the plan therefore weight a 1h write at 1.1 times a 5m write and a read at 0.033 of a 5m write; API-key cost models keep the list prices of CTX-303 and CTX-511.
