# Read Pointed-At Files in Full

## Context and Problem Statement

The user pointed the agent at rule files and dossiers; the agent cited them unread.

## Considered Options

- Read in full.
- Skim or cite.

## Decision Outcome

Chosen: The agent reads the whole of each file the user points at. Superseded the same day for large files.

## Consequences

Costly for large files.
