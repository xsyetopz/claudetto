# Skills, Commands and Agents Requirements

claudetto and claudetto-spec ship a small set of skills, commands and agents, because each description sits in every request's listing and the studies in reports/2026-11-21-research/skills-catalog.md find that focused skills beat large bundles and that loaded skills cause failures of their own (307 in one study). An item ships only with an eval case that runs it against vanilla Claude Code 2.1.330 and scores no lower (ADR-0177). The catalog read 15 sources (specs/evidence/sources.md) and 28 candidates; none reports a measured outcome for a listed skill or agent, so the set below is the catalog's recommendation and each new item starts as "eval first".

The user's settings bound the design: `skillListingMaxDescChars: 200` (claudetto's default since 2026-11-26, RISK-561; 60 before) cuts each listed description at 200 characters, so the trigger sits in those characters; `disableBundledSkills: true` turns off the bundled `/code-review` and `/simplify` and leaves plugin skills listed.

## Core Plugin

- [x] **SKILLS-010** claudetto shall ship `/claudetto:review`, a user-invoked command that reviews the working diff in a forked context for defects only (no style), returns findings as `path:line` with the failing input, and edits nothing.
  Acceptance: an eval case `review-seeded-defects` (a fixture diff with 5 seeded defects and 3 benign changes, outcome-only grader on defects named with file and line) scores recall no lower and false findings no higher than vanilla asked to "review the diff", n=3 per arm, `--no-publish` and a cost cap; the description's first 60 characters name the trigger. If the arms tie, the command is removed. Verification: eval.
  Status: removed by its acceptance rule (2026-11-21, 2.1.330, Opus 5.5, issue #156). At n=10 per arm the first runs scored with 0.76 vs without 0.90 on `review-seeded-defects-slash` and 0.75 vs 0.79 on `review-seeded-defects`. Two causes: the benign `formatPrice` helper (B3) was wrong for negative cents (`formatPrice(-150)` gave `$-2.-50`), so both arms reported a real defect as a false finding; and the command listed changes it had checked and cleared (`src/cart.js:1` "this rename is clean"). With B3 replaced by a correct helper and the command told to report defects only, the arms tie: slash 0.95 vs 0.95 (n=10, $1.79), plain 0.90 vs 0.90 (n=10, $3.91). A plain request to review the diff does as well, so the command, its skill and the slash case are removed; `review-seeded-defects` stays as the review regression case.
  Verified: PASS: `plugins/claudetto/evals/results/2026-11-21T20-45-41-658Z` and `2026-11-21T20-45-41-655Z` (`aggregate-result.json`, local, gitignored).
  Status: restored 2026-11-24: commit 2d2a47a7d (#176) wrote the SKILLS-021 ship status over the first Status line, which is back to its text at 2d2a47a7d^, and that status now sits under SKILLS-021.
  Verified: 2026-11-24, claude 2.1.329: the removal holds. `plugin details claudetto` lists Skills 0, and `review-seeded-defects`, the regression case, scored 0.96 against 0.96 on Opus 5.5 (`just eval claudetto -j 4`, `results/2026-11-24T03-08-24-156Z`): one false finding in 2 claudetto runs (`b4-false-rename`) and 2 in 1 vanilla run (`b4`, `b5`).
