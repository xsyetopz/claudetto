Asks a stronger model for advice on a hard problem, a plan, or a stuck task.
Use it before a large change, or when a check keeps failing.
The tool sends the question, the plan, the failing checks, and the end of the conversation to the model.
Put no secret in the question.
Do not use it for a question with a fixed set of options. Use `second_opinion` for that question.
The tool has a limit of calls in one turn and in one session.
