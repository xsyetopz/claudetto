Jev may answer a question in place of the user, from the question text and the option texts alone.
Jev cannot read a file or this session.
Put the facts that decide the question in the question and in the option descriptions: the file lines and the tool results, with their sources.
Do not put a secret, a key, or personal data in the question, because the text goes to the TypeSafe API.
When Jev is not sure, the user answers the dialog.
An approval question goes to the user, never to Jev: a question that asks the user to approve money, a push, a release, a delete, or a step that cannot be undone.
State in the question that it asks for approval, so that the user gets the dialog.
