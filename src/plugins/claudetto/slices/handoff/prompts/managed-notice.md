The handoff of a compaction is off, because Claude Code manages this machine and gives `session.compact` only to the plugins in the managed `appendPlugins` list. Compaction runs as built in, and `/handoff` still works. To turn on the handoff of a compaction, add `"appendPlugins": ["{{id}}"]` and `"enabledPlugins": {"{{id}}": true}` to the managed settings. `/handoff-setup` shows the steps.
