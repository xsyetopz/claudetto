# Claude Code Environment Variables: Cloud Providers

These 81 environment variables of Claude Code `2.1.303` cover Amazon Bedrock, Google Vertex AI, Microsoft Foundry, and gateway settings.
They pick which cloud serves the model and where its credentials come from.
An environment variable is a named setting that you put in your shell or in the `env` key of `settings.json`.

## Example

Run `export CLAUDE_CODE_USE_BEDROCK=1` before `claude` to send requests to Amazon Bedrock.
Or put `{ "env": { "CLAUDE_CODE_USE_BEDROCK": "1" } }` in `~/.claude/settings.json`.

| `ANTHROPIC_AWS_WORKSPACE_ID` | ✅ | Workspace ID for Claude Platform on AWS. Claude Code shows it as `Workspace ID` and passes `workspaceId` to the AWS client. | Text, headers by default. The client gets `workspaceId` only when this var is set and an `anthropic-workspace-id` header exists in the default headers. Header source not traced | Provider `anthropicAws`. Not set from project `env` before trust |
| `ANTHROPIC_BEDROCK_BASE_URL` | ✅ | Overrides the Amazon Bedrock endpoint URL. | Text. Defaults are `https://bedrock-runtime.<region>.amazonaws.com` for requests and `https://bedrock.<region>.amazonaws.com` for the control plane | Provider `bedrock`. Not set from project `env` before trust |
| `ANTHROPIC_BEDROCK_MANTLE_BASE_URL` | ✅ | Overrides the Amazon Bedrock Mantle endpoint URL. | Text. Default is `https://bedrock-mantle.<region>.api.aws` | Provider `mantle`. Not set from project `env` before trust |
| `ANTHROPIC_BEDROCK_REGION_PREFIX` | ✅ | Sets the cross-region inference profile prefix that Claude Code tries first. Ignored in `us-gov-` regions. | One of a fixed set of values. Without it, Claude Code derives `us`, `eu`, `apac`, or `global` from the AWS region. Docs add `jp` and `au` | Provider `bedrock`. Project `env` can set it before trust |

| `ANTHROPIC_FOUNDRY_BASE_URL` | ✅ | Sets the full base URL of the Foundry resource. | Text. Wins over `ANTHROPIC_FOUNDRY_RESOURCE`. Without both, the URL is undefined | Provider `foundry`. Not set from project `env` before trust |
| `ANTHROPIC_FOUNDRY_RESOURCE` | ✅ | Sets the Foundry resource name. Claude Code builds `https://<resource>.services.ai.azure.com` from it. | Text. Checked as a resource name. An invalid value with no base URL raises an error | Provider `foundry`. Not set from project `env` before trust |
| `ANTHROPIC_GOOGLE_CLOUD_BASE_URL` | 🔍 | Overrides the endpoint for the Claude Platform on Google Cloud provider. | Text. Default is `https://claude.googleapis.com`. | `ANTHROPIC_GOOGLE_CLOUD_PROJECT` | 🔍 | Sets the GCP project for the Claude Platform on Google Cloud provider. | Text. Falls back to `GOOGLE_CLOUD_PROJECT` in the status view. Also feeds Google auth when no other project var is set | Provider `anthropicGoogleCloud`. Not set from project `env` before trust |
| `ANTHROPIC_GOOGLE_CLOUD_WORKSPACE_ID` | 🔍 | Sets the workspace ID for the Claude Platform on Google Cloud provider. The status view shows it. | Text. Passed to the client setup with the project and location | Provider `anthropicGoogleCloud`. Not set from project `env` before trust |
| `ANTHROPIC_SMALL_FAST_MODEL_AWS_REGION` | ✅ | Overrides the AWS region for the Haiku-class model on Bedrock. | Text | Providers `bedrock` and `mantle`. Project `env` can set it before trust |
| `ANTHROPIC_VERTEX_BASE_URL` | ✅ | Overrides the Vertex endpoint URL. | Text, comes by default. A set value also turns off the default for fine-grained tool streaming on Vertex | Provider `vertex`. Not set from project `env` before trust |

| `AWS_ACCESS_KEY_ID` | ✅ | Standard AWS access key. Claude Code reads it into the Bedrock credential set, and uses it with the secret key for AWS-based federation. | Text | Providers `bedrock` and `mantle`. Not set from project `env` before trust |
| `AWS_CONFIG_FILE` | ✅ | Standard AWS config file path. Claude Code uses it in the AWS cache key and as an input of the auth refresh check. | Text. Key is config file, credentials file, and profile. A host-managed provider check also tests it | Providers `bedrock` and `mantle`. Not set from project `env` before trust |
| `AWS_CONTAINER_CREDENTIALS_FULL_URI` | 🔍 | Standard AWS container credentials URL. Claude Code includes it in the inputs that refresh cached AWS credentials. | Text | Providers `bedrock` and `mantle`. Not set from project `env` before trust |
| `AWS_CONTAINER_CREDENTIALS_RELATIVE_URI` | 🔍 | Standard AWS container credentials path. Claude Code includes it in the inputs that refresh cached AWS credentials. | Text | Providers `bedrock` and `mantle`. Not set from project `env` before trust |
| `AWS_DEFAULT_REGION` | ✅ | Standard AWS region. It is the fallback for `AWS_REGION`. Claude Code defaults to `us-east-1` when neither is valid. | Text. Order is `AWS_REGION`, then this var, then the shared config, then `us-east-1` | Providers `bedrock` and `mantle`. Project `env` can set it before trust |
| `AWS_ENDPOINT_URL` | ✅ | Sets a global AWS endpoint override. Claude Code uses it as a fallback STS URL and counts it as a Bedrock base URL source. | Text. | `AWS_ENDPOINT_URL_BEDROCK` | ✅ | Overrides the Bedrock endpoint URL. Claude Code lists it as a Bedrock base URL source for provider checks. | Text. In the Bedrock variable list after `ANTHROPIC_BEDROCK_BASE_URL` and `AWS_ENDPOINT_URL_BEDROCK_RUNTIME` | Bedrock. Not set from project `env` before trust |
| `AWS_ENDPOINT_URL_BEDROCK_RUNTIME` | ✅ | Overrides the Bedrock runtime endpoint URL. Claude Code lists it as a Bedrock base URL source for provider checks. | Text. In the Bedrock variable list right after `ANTHROPIC_BEDROCK_BASE_URL` | Bedrock. Not set from project `env` before trust |

| `AWS_ROLE_ARN` | 🔍 | Gives the role for AWS web identity login. Claude Code also uses it as a credential source marker for Bedrock auth refresh. | Text | Bedrock |
| `AWS_SECRET_ACCESS_KEY` | ✅ | Gives the AWS secret key for Bedrock. It pairs with `AWS_ACCESS_KEY_ID` and `AWS_SESSION_TOKEN`. | Text. | `AWS_SESSION_TOKEN` | ✅ | Gives the temporary AWS session token that goes with the access key pair for Bedrock. | Text. Claude Code also writes it into an env object built from a Bedrock access key setup | Bedrock. Not set from project `env` before trust |
| `AWS_SHARED_CREDENTIALS_FILE` | ✅ | Sets the path of the AWS shared credentials file for Bedrock. | Text. Path string. Part of the credential fingerprint and the `awsAuthRefresh` cache key | Bedrock. Not set from project `env` before trust |
| `AWS_USE_FIPS_ENDPOINT` | ✅ | Selects the FIPS STS endpoint for the gateway role assume code. | Text. True only for the exact string `true` | Gateway STS (AWS identity federation) |
| `AWS_WEB_IDENTITY_TOKEN_FILE` | ✅ | Gives the path of the web identity token file for AWS role login. Claude Code also uses it as a credential source marker. | Text. Path string | Bedrock |
| `CLAUDE_CODE_AGENT_PROXY_GH_SHIM` | 🔍 | Makes the CCR agent proxy write a `gh` shim onto `PATH`. | On or off. Claude Code sets `1` for the session when the tool config has `ghPathShim`. A failed write logs a warning | Claude Code on the web with agent proxy. Not set from project `env` before trust |
| `CLAUDE_CODE_AGENT_PROXY_GIT_CONFIG` | 🔍 | Makes the CCR agent proxy append a governed git config. | On or off. Claude Code sets `1` for the session when the tool config has `gitConfig`. | `CLAUDE_CODE_AGENT_PROXY_GIT_HOSTS` | 🔍 | Lists the governed git hosts for the CCR agent proxy. | A comma-separated list, host by default. Claude Code ignores bad entries and logs the count. | `CLAUDE_CODE_AWS_CHAIN_RESOLVE_TIMEOUT_MS` | ✅ | Sets how long Claude Code waits for the AWS default credential chain before the request fails. | A number of milliseconds, `60000` by default. Whole number from `1` to `2147483647` ms | Bedrock, Mantle, Claude Platform on AWS |
