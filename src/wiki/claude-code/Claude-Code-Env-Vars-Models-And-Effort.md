# Claude Code Environment Variables: Models and Effort

These 91 environment variables of Claude Code `2.1.303` cover the model, how hard it thinks, fast mode, and output size.
They let you change the model or the thinking effort without a command.
An environment variable is a named setting that you put in your shell or in the `env` key of `settings.json`.

## Example

Run `export ANTHROPIC_MODEL=opus` before `claude` to start every session with the `opus` model.
Or put `{ "env": { "ANTHROPIC_MODEL": "opus" } }` in `~/.claude/settings.json`.
