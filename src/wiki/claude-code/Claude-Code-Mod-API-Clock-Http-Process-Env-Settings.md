# Mod API: Clock, HTTP, Process, Env, and Settings

These five nouns reach the machine: `$.clock` for time and timers, `$.http` for web requests, `$.process` for commands, `$.env` for environment variables, and `$.settings` for the merged settings.
`$.process` works in the CLI only.
`$.settings` is read only.
Example: `const { exitCode, stdout } = await $.process.run(["git", "status"])`.

In the "Where" column, **Run time** means in a hook, in a closure that a hook drew, or in a timer callback.
It does not mean inside `register`.

Resolves `{ status, ok, headers, text }`. | Run time. | `CoreEngineInterface` line 3572, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `$.process.run` | Runs a command on the host by its argument vector (no shell) and resolves `{ exitCode, stdout, stderr }` once it exits, any exit code. | Type: `(argv: readonly string[], init?: ProcessRunInit) => Promise<ProcessRunResult>`. Runs a command to the end. | ✅ | `$.env.get` | Resolves with the variable's value, or `undefined` when it is unset. | Type: `(name: string) => Promise<string \| undefined>`. `name` must be a string literal. `claude plugin validate` lists the names your module reads. | ✅ | `$.env.set` | Sets the variable for this process and everything it starts after, or unsets it when `value` is `undefined`. | Type: `(name: string, value: string \| undefined) => Promise<EnvSetResult>`. `name` must be a string literal. Resolves `{}` or `{ deny }`. Example: `await $.env.set("GIT_PAGER", "cat")`. | Name must be a string literal in the module source. | `CoreEngineInterface` line 3692, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `$.settings.read` | Resolves with the settings merged over every source, as the engine reads them, or with one source's settings as loaded (`{ source }`). | Type: `(args?: SettingsReadArgs) => Promise<Settings>`. Returns a snapshot in plain data. `{ source }` reads one source. The merge takes a key from the last source that has it. | Run time. | `CoreEngineInterface` line 3660, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
