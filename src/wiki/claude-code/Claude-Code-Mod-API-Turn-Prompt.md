# Mod API: Turn and Prompt

`$.turn` ends the running turn.
`$.prompt` sends a prompt as a user turn and works with the prompt box.
The events follow a turn from start to end, and they cover the system prompt, the context blocks, and attachments.
This hook trims the whitespace of every prompt before the model reads it:

```javascript
on('prompt.submit', async ($, e, next) => next({ ...e, text: e.text.trim() }))
```

In the "Where" column, **Run time** means in a hook, in a closure that a hook drew, or in a timer callback.
It does not mean inside `register`.

## Engine Events

| ✅ | `prompt.submit` | Fires when a prompt is submitted, before the turn starts. `next(e)` runs the hooks beneath and the UserPromptSubmit settings hooks, then it enters. | Input `PromptSubmitInput`.
