# Mod API: UI Events

These events fire when Claude Code draws part of the interface, and when a person uses a control that a mod drew.
The second table lists the events that the `$.ui` methods raise.
This hook adds a count to the spinner:

```javascript
on('ui.render', { component: 'Spinner' }, async ($, e, next) =>
  next({ ...e, props: { ...e.props, suffix: ' · tool calls: ' + calls + '…' } }))
```

## Engine Events

| Mark | Item | What it does | How it works | Where it can be used | Source |
| --- | --- | --- | --- | --- | --- |
| ✅ | `ui.render` | Fires when the engine is about to draw a component: once per input value (props, viewport width), plugin load or `$.ui.invalidate("ui.render")`. | Input `RenderInput`. Result `RenderElement`. Hook result: the tree to draw. `next(e)` gives the engine's drawing. An invalid tree draws the engine's drawing. | Hook via `on('ui.render', ...)`. Also callable as `$.ui.render(...)`. | `EngineEventOf` line 4080, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.resolve` | Fires when the plugins load (not per draw), once per surface, component and plugin: `e` names the surface and component, never the props. | Input `ResolveInput`. Result `ElementTable`. Hook result: the element table of the surface. A hook may restyle an element or leave one out. | Hook via `on('ui.resolve', ...)`. Also callable as `$.ui.resolve(...)`. | `EngineEventOf` line 4089, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.press` | Fires when a `Button` a render hook drew is pressed on a surface, `e` is `{ plugin, element, component, surface }`, `element` the button's `key`. | Input `UiPressArgument`. Result `UiPressResult`. Hook result: `{ element }`. `next(e)` lets the press through. Returning `{ element }` takes it. | Hook via `on('ui.press', ...)`. | `EngineEventOf` line 4098, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.input` | Fires when an `Input` a render hook drew changes or is submitted, `e` is `{ plugin, element, component, surface, kind, value }`. | Input `UiInputArgument`. Result `UiInputResult`. Hook result: `{ element, value }`. `next({ ...e, value })` rewrites the typing. | Hook via `on('ui.input', ...)`. | `EngineEventOf` line 4107, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.select` | Fires when a `Select` a render hook drew is picked from, `e` is `{ plugin, element, component, surface, value }`. | Input `UiSelectArgument`. Result `UiSelectResult`. Hook result: `{ element, value }`. `next({ ...e, value })` rewrites the pick. | Hook via `on('ui.select', ...)`. | `EngineEventOf` line 4116, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.message` | Fires when a `Client` THIS plugin drew posts from its surface module (`surface.post(data)`), only this plugin's hooks see it. | Input `UiMessageArgument`. Result `UiMessageResult`. Hook result: `{ props? }`. `next({ ...e, data })` rewrites the data. One call for each instance in each frame. | Hook via `on('ui.message', ...)`. | `EngineEventOf` line 4125, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.fault` | Fires when a `Client` THIS plugin drew failed on a surface: its module did not load, its drawing failed, or its code failed after it had drawn. | Input `UiFaultInput`. Result `UiFaultResult`. Hook result: `{}`. Only this plugin's hooks see it. `e.phase` says when and `e.reason` says why. | Hook via `on('ui.fault', ...)`. | `EngineEventOf` line 4139, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.scroll` | Fires before a site's window moves: the person's wheel or scroll keys on a `Pane` body or the `AbovePrompt` band, at its edges too, `$.ui.scroll`. | Input `UiScrollInput`. Result `UiScrollResult`. Hook result: `{}` or `{ deny }`. `next({ ...e, offset })` scrolls elsewhere. | Hook via `on('ui.scroll', ...)`. Also callable as `$.ui.scroll(...)`. | `EngineEventOf` line 4151, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
| ✅ | `ui.focus` | Fires before a site's focus ring moves: the person's Tab, arrows or click in a `Pane` or the band, an `autoFocus` element taking it, `$.ui.focus`. | Input `UiFocusInput`. Result `UiFocusResult`. Hook result: `{}` or `{ deny }`. `next({ ...e, element })` moves the focus to another element. | Hook via `on('ui.focus', ...)`. Also callable as `$.ui.focus(...)`. | `EngineEventOf` line 4163, [Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) |
