# Settings Snippet Docs

This page gives the settings lines of the `claudetto-docs` add-on.
Add these lines only when you install `claudetto-docs` ([Library docs](Library-Docs)).
Merge them into the `permissions.allow` list and the `sandbox.network.allowedDomains` list of the [settings snippet](Settings-Snippet).
When `claudetto-docs` is installed, `/claudetto:setup` adds them.
