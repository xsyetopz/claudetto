# Release History

This page tells which releases exist and where their notes are.
Read it when you need the notes of a release.

## 1.0.0

The notes of 1.0.0 are in [CHANGELOG.md](https://github.com/xsyetopz/dotclaude/blob/main/CHANGELOG.md), under `[1.0.0]`.
1.0.0 has no tag yet, so its section holds the changes of the release in progress.
`just bump` changes the version in `package.json`.
`just generate` copies that version to each `plugin.json`.

## 0.x Releases

The 0.x releases have one archive page for each release line.
The pages run from `Release-0.1-0.2` to `Release-0.28`.
The [Archive](Archive) page is the index of these pages.
The `Older Releases` table of `CHANGELOG.md` links to them too.
