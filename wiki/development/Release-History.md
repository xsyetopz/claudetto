# Release History

This page tells which releases exist and where their notes are.
Read it when you need the notes of a release.

## The Release in Progress

The release in progress is `claudetto` 0.1.0, and its package version is `0.1.0-alpha.1`.
The notes of the release are in [CHANGELOG.md](https://github.com/xsyetopz/claudetto/blob/main/CHANGELOG.md), under the version that the manifests give.
That version has no tag yet, so its section holds the changes of the release in progress.
`just bump` changes the version in `package.json`.
`just generate` copies that version to each `plugin.json`.

## The Release 1.0.0 of `dotclaude`

`claudetto` 0.1.0 restarts the project of the earlier plugin `dotclaude`.
The notes of `dotclaude` 1.0.0 are on the [Release 1.0](Release-1.0) archive page.
The `Older Releases` table of `CHANGELOG.md` links to it.

## 0.x Releases

The 0.x releases have one archive page for each release line.

The [Archive](Archive) page is the index of these pages.
The `Older Releases` table of `CHANGELOG.md` links to them too.
