# Release History

This page tells which releases exist and where their notes are.

## 1.0.0

The notes of 1.0.0 are in [CHANGELOG.md](https://github.com/xsyetopz/dotclaude/blob/main/CHANGELOG.md), under `[Unreleased]`.
The version in `package.json` changes with `just bump`, and `just generate` copies it to each `plugin.json`.

## 0.x releases

The 0.x releases have one archive page for each release line, from `Release-0.1-0.2` to `Release-0.28`.
The [Archive](Archive) page is the index of these pages.
The `Older Releases` table of `CHANGELOG.md` links to them too.
